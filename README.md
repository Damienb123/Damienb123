### About Me

🎓 Recent Computer Science graduate from the University of Texas at San Antonio (UTSA), with a concentration in Software Engineering (December 2025)

🔭 Currently building Sports Talk, a real-time sports discussion platform using Next.js, TypeScript, React, Supabase, and PostgreSQL

🚀 Passionate about full-stack development, UI/UX design, software testing, and AI, with a focus on building intuitive, scalable, and reliable applications

🛠️ Previously worked as a Full Stack Engineer Intern at Neuron, shipping production features and integrating Auth0 and Stripe into SaaS applications

🧪 Built Documentation Drift Detector, a published VS Code extension used by 80+ developers to identify documentation-to-code inconsistencies

🤖 Explored AI-powered applications during my time as a Headstarter AI Software Engineering Fellow, building with Next.js, Firebase, and the OpenAI API

🌱 Currently sharpening my skills in modern web architecture, automated testing, and user-centered design, while exploring new ways to integrate AI into everyday applications
